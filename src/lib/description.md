My personal work focuses on the hard parts of the stack. Projects often sit close to the boundary between product and infrastructure: decentralized P2P systems with Rust and Tauri, local-first security tools, programming languages, terminal workflows, Linux security, embedded sensing, and bare-metal AArch64 environments.

I care about software that is understandable, controllable, and useful. I prefer designing robust back-end logic and secure systems over high-level UI tweaking, but I’m comfortable delivering the full vertical—from hardware-adjacent code to the user interface. That usually means designing the architecture, implementing the core, documenting the decisions, and making the result usable enough that someone else can try it.
