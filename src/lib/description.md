I’m a Computer Engineering student who likes building complete systems from first principles. I’m driven by technical efficiency, curiosity, and a bias toward making things work end-to-end instead of only exploring isolated pieces.

My personal work focuses on the harder parts of the stack, usually near the boundary between product and infrastructure: decentralized P2P systems with Rust and Tauri, terminal password managers, programming languages, AI-native terminal tools, Linux security, embedded sensing, and bare-metal AArch64 environments. Alongside that, I have production experience maintaining real-world web and mobile architectures with NestJS, Angular, and React Native, which gave me a practical sense of how software evolves once real users and real constraints are involved.

I care about software that is understandable, controllable, and useful. I enjoy designing the core architecture, implementing the difficult parts, documenting the decisions, and shaping the result into something usable enough that someone else can actually try it. I tend to prefer robust back-end logic, security-sensitive systems, and infrastructure-heavy problems, but I’m comfortable carrying a project across the full vertical—from hardware-adjacent code to the user interface.
